# Exercises

All exercises are done on a **scratch remix**. Never on the live venue, never on a client project.

Payment work is always in the payment provider's **test mode**.

| # | Module | Task | Done when |
| --- | --- | --- | --- |

| 4 | 02 | Make one tiny, precisely described change | Lands correctly first try |
