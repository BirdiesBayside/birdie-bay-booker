# Developer Training Course

A self-paced course for a new developer joining the team to build client venue platforms with
Lovable, based on a remix of this project.

**Assumes:** no knowledge of this codebase, and very little backend knowledge.
**Produces:** someone who can take a remix from empty to a live client venue hub, safely.

## How this differs from `docs/platform/**`

| Folder | What it is |
| --- | --- |
| `docs/platform/**` | The reference manual. Deep, precise, technical. The source of truth. |
| `docs/bay-controller-product/**` | The Windows app spec and strip-down pack. |
| `docs/training/**` (this folder) | The teaching layer. Plain English, ordered, with exercises. Links to the manual instead of repeating it. |

If training and the reference manual ever disagree, **the reference manual wins** — and tell the
trainer so it gets fixed.

## Suggested pace

Roughly two weeks part-time.

| Days | Work |
| --- | --- |
| 1 | Modules 00–03 |
| 2–3 | Modules 04–05 |
| 4 | Modules 06–07 |
| 5 | Module 09 (and 08 if relevant) |
| 6–7 | Module 10 — build a scratch client end to end |
| 8 | Modules 11–12 and the final practical |

## Prerequisites

- A Lovable account, added to the team.
- Access to a **scratch remix**. Never the live venue project.
- Basic comfort with a web browser dev console. No prior React or SQL required.
